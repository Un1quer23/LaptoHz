# 笔记本适配记录

版本：0.3.0-beta.5；日期：2026-10-06。本版增加失败恢复后的回读验证，保留三种模式、确认流程、9 秒结果提示和物理档位筛选。以 Windows 报告的物理显示能力适配，不以品牌白名单控制运行。相同型号也可能因面板、显卡路线、分辨率或驱动版本不同而有不同档位。

## 实测机型

| 机型 | 环境与档位 | 结论 |
|---|---|---|
| ThinkBook 16p 2025，LENOVO 21R0 | Windows 11 x64；MNG007DA6-2，2560×1600、32bpp；Intel Graphics／NVIDIA RTX 5060 Laptop GPU；物理 60／240Hz | 本机检测、逐档实际切换、统一菜单与应用重启回归通过；虚拟 30／48／120Hz 已过滤；真实插拔、睡眠、重登及多屏仍待验收，详见 VALIDATION.md |

本表不能推断同品牌其他型号已经通过实测。

beta.5 的恢复失败、取消、输出能力变化和分数频率分支通过后端注入测试验证；实机仅重新执行本机当前支持的物理 60／240Hz 切换并恢复原状态。模拟测试与实机结果分别记录在 [验证记录](../VALIDATION.md)，未主动制造真实驱动故障。

ThinkBook 本机图形内核报告 60／240Hz 为物理档位，30／48／120Hz 设置了虚拟刷新率标记。上一测试版实际切换时，30／48Hz 桌面的信号为 60Hz，120Hz 桌面的信号为 240Hz；本版不再将这些虚拟值作为可选目标。其他设备若确有物理 30／48／120Hz，仍可按能力通过校验后提供。

## 待实测组合

模拟策略覆盖 60／90、60／120、60／144、60／165、60／240、高刷新率单独组合、仅一个档位、低于 60Hz 和含 30／48Hz 的组合。模拟结果验证软件行为，不能替代具体机型的硬件切换。

还需要其他 Windows 11 x64 笔记本补充实测，特别是 Intel／AMD 核显内屏、不同 NVIDIA 输出路线、59.94／119.88 等分数频率、不同缩放比例与扩展显示器。收到报告后分别记录“仅检测通过”和“完整实测通过”，不自动升级为已验证。

## 明确不执行的状态

复制显示源、多个内屏、远程／非活动会话、DRR 开启时保持显示状态并说明原因；内屏关闭时等待恢复；物理能力读取失败、只有虚拟模式或没有通过校验的物理档位时不提交切换。这些是运行状态边界，不是某个品牌的不兼容名单。

## 其他设备验收步骤

1. 固定 EXE 位置，运行 `--diagnose --output diagnostics.json`，保留版本、机型、显卡、内屏和逐档校验信息。报告不包含序列号，也不会自动上传。
2. 比对 Windows 高级显示中的分辨率和可选档位；进入手动模式逐档测试，检查实际回读、屏幕恢复和其他显示参数，最后恢复原档位。
3. 设置插电／电池目标，检查自动模式真实插拔、确认模式的确认／保持／×，以及手动模式不被供电变化覆盖。
4. 检查重复通知、睡眠期间换电源、锁屏／息屏恢复、扩展显示器及不同 DPI 的菜单定位；按设备支持情况分别检查 HDR 和显卡路径变化。
5. 重启应用验证模式、目标及关闭自启的选择；真正重登验证登录自启。逐项填写通过／失败／未测，保留失败原因和驱动版本。

可分享本地报告和验收结论来补充适配列表；日志如含本地路径，可在分享前自行检查。当前测试版不保证所有机器或运行状态都能切换。
